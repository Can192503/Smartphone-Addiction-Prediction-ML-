# Smartphone-Addiction-Prediction-ML-
A machine learning project on Kaggle that predicts smartphone addiction, and its ROC score.
# Kaggle Playground Series - S6E8 Solution

Bu repo, [Kaggle Playground Series S6E8](https://www.kaggle.com/competitions/playground-series-s6e8/overview) yarışması kapsamında geliştirilen makine öğrenmesi modelini ve veri analizi süreçlerini içermektedir.

## 🚀 Proje Hakkında
Bu yarışmada amaç, Akıllı telefon bağımlılığını farklı parametrelere göre tahminini yapmak ve roc skorumuzu belirlemek. Bu projede veriyi ön işleme sokarak, uygun model mimarileriyle tahminler ürettik.

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler
* **Python** 
* **Pandas / NumPy** (Veri manipülasyonu ve analizi)
* **Scikit-Learn** (Veri ön işleme ve modelleme)
* **CatBoost / XGBoost / LightGBM** (Makine öğrenmesi algoritmaları)

## 📂 Proje Yapısı
- `data/`: Veri setlerinin bulunduğu klasör (büyük dosyalar gitignore ile hariç tutulmuş olabilir).
- `notebooks/`: Keşifsel veri analizi (EDA) ve model denemelerinin yapıldığı Jupyter notebook'lar.
- `src/` veya ana dizin: Python kodları ve model eğitim scriptleri.

## 📈 Model ve Sonuçlar
Veri ön işleme adımlarının ardından çeşitli modeller denenmiş ve doğrulama (validation) skorlarına göre en iyi sonuç veren yaklaşım seçilmiştir.
